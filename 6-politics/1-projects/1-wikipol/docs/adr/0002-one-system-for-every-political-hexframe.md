# Every political hexframe lives in my System

Sources, my World view and the hexframes to come (geopolitics, French parties) all hang under Politics in my own System, Sources beside the projects that build it. A hexframe Reference points only at a Tile of the same System, and these hexframes exist to cite one another's Digests, so a Wikipol Organization, which would be easier to share, is ruled out until References cross Systems. Moving a tree between Systems later breaks every Reference into it.
