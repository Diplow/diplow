# Claude sessions

The discussions about politics I have with Claude that are worth keeping: one file per session, in French, recording the question, what Claude found and from where, where I disagreed and what came out of it. They feed [[6-politics/-position|my position]] and show how wikipol answers in practice.

Sessions are filed by date like a Source's Chronicle ([[6-politics/1-projects/1-wikipol/docs/adr/0001-chronicle-splits-by-count|ADR 0001]]): this node holds up to six sessions, numbered in the order they happened. The seventh splits it into Periods, `1-YYYY-MM-DD/` folders that each hold six sessions at most, each with its own `CLAUDE.md`.

Each session is a private file (`-N-slug.md`): its name stays public, so the slug says what the session tested rather than what was argued.
