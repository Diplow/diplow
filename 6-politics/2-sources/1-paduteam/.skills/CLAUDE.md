# PaduTeam's skills

The skills that were `Skills/` in the Graphiked vault. A skill here overrides the one of the same name in [[6-politics/1-projects/1-wikipol/CLAUDE|wikipol]]'s `Skills/`: look for `.skills/*/<name>/SKILL.md` before `wikipol/Skills/<name>/SKILL.md`. The folder is the skill's name, so the group in between never changes which skill wins.

| # | Group | Skills |
|---|---|---|
| 1 | [[6-politics/2-sources/1-paduteam/.skills/1-ingest/CLAUDE\|ingest]] | `gather-context`, `ingest-batch`, `ingest-video` |
| 2 | [[6-politics/2-sources/1-paduteam/.skills/2-write-basic/CLAUDE\|write-basic]] | `write-concept`, `write-entity`, `write-evenement`, `write-video` |
| 3 | [[6-politics/2-sources/1-paduteam/.skills/3-write-advanced/CLAUDE\|write-advanced]] | `write-conjoncture`, `write-enjeu`, `write-methode`, `write-possible` |

Every one of them writes vault notes, and the vault is frozen in `wikipol/Legacy/Paduteam/`: they stay here as the record of how PaduTeam was read, not to be run.
