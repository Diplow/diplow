# Principles

How I think software is built in the AI era. Each principle is light but opinionated direction, the kind agents follow and humans own (see [[4-software-engineering/2-principles/2-ai-first/CLAUDE|AI-first]]).

| # | Principle | In one line |
|---|---|---|
| 1 | [[4-software-engineering/2-principles/1-domain-driven-design/CLAUDE\|Domain-driven design]] | Business logic lives in domains with a strict language; humans own the domains |
| 2 | [[4-software-engineering/2-principles/2-ai-first/CLAUDE\|AI-first]] | Steer AI with principles, and block it as little as possible |
| 3 | [[4-software-engineering/2-principles/3-feedback/CLAUDE\|Feedback]] | Types, tests and a browser let agents check their own work |
| 4 | [[4-software-engineering/2-principles/4-mapping-modules/CLAUDE\|Mapping modules]] | A map of modules and their links shows a system without reading its code |
| 5 | [[4-software-engineering/2-principles/5-maintainability/CLAUDE\|Maintainability]] | The next reader holds the smallest possible mental model |
