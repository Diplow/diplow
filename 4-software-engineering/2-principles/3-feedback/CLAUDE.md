# Feedback

Fast, rich and automated feedback was already understood as valuable before AI. With agents doing the work, it is even more obvious.

- **Type safety** brings tremendous value, and has a natural synergy with [[4-software-engineering/2-principles/1-domain-driven-design/CLAUDE|domain-driven design]]: a domain already has a strong, well-defined vocabulary, its ubiquitous language, and precise, meaningful types extend it into the code.
- **Automated tests**, for the same reason.
- **A browser** the agents can drive (for example claude-in-chrome), so they see what they built.
