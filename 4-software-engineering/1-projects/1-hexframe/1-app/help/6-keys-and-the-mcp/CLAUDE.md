An agent, Claude Code for one, reaches your System through hexframe's **MCP server**, at `/mcp`. It proves who it works for with a **Key** you issue.

With it, the agent reads your System the way you laid it out, and changes it with the same operations you have in the app. It reads Help the same way.

Its Children: what a Key is, then what the MCP server offers.
