# chat

The Chat, the side of hexframe's screen that shows the Conversation, where the user and the agent act ([[4-software-engineering/1-projects/1-hexframe/1-app/src/front/ui/CLAUDE|ui]], "hexframe's screen, in words"). Its components came as the proposals for the chat landed (HEX-98, HEX-99, HEX-100); `features/conversation/` draws home's Conversation with the text, the entries and the composer (HEX-101), `features/system/` the tile widget at its foot (HEX-102), and the other widgets wait for their build (HEX-103). The Chat never imports the Canvas (dependency-cruiser, `no-side-importing-the-other`): a piece both use moves to `ui/atoms/` or `ui/layouts/`.

Every piece takes its text as `Words` (`text/words.tsx`): plain words, a tile named, who acted by name, a command named, which a click runs, in the order its language says them, so a tile reads alike in a Message, an event, a Proposal's change and a receipt. A feature makes them from a message with `weave`, which reads the message with a mark in each tile's place, then weaves the tiles in where the marks landed, a command as a tile is.

Wide, every piece that reaches the chat's lines' end follows the curve the chat is cut along: it runs on to it at its own height, the chat's gap short of it, so the conversation's right side is the curve's and nothing lines up in a column against it, a message line by line, an event and its time, a receipt, a day's split, the thinking, a widget's head, body, actions and rows, the composer's rows and its list (`toCurve`, `ui/layouts/`); a widget's tools ride just inside it (`useAlongCurve`). A piece beside another, a field in a row of two, stays where it is.
