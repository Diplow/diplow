# chat

The Chat, the side of hexframe's screen that shows the Conversation, where the user and the agent act ([[4-software-engineering/1-projects/1-hexframe/1-app/src/front/ui/CLAUDE|ui]], "hexframe's screen, in words"). Its components come as the proposals for the chat land (HEX-98, HEX-99, HEX-100), and HEX-101 wires them in; until then the Conversation is drawn by `features/conversation/` from the shared pieces. The Chat never imports the Canvas (dependency-cruiser, `no-side-importing-the-other`): a piece both use moves to `ui/atoms/` or `ui/layouts/`.

Every piece takes its text as `Words` (`text/words.tsx`): plain words, a tile named, who acted by name, in the order its language says them, so a tile reads alike in a Message, an event, a Proposal's change and a receipt. A feature makes them from a message with `weave`, which reads the message with a mark in each tile's place, then weaves the tiles in where the marks landed.

- **The agent's words as Markdown** wait for the seam's renderer: `Words` keeps the line breaks, not yet the emphasis, the code and the lists.
- **Editing a Message** waits for its feature and for TanStack Hotkeys.
