# conversation

What the chat beside the canvas shows: one timeline per Account, a day at a time, newest at the bottom beside the input. Home lays it out in the side column over the Account's own Conversation (`Chat`); `/dev/system` lays out the same `Conversation` on fixtures. The user `@`s a Tile as they write, and the Message keeps it by its id; a Message's link shows the Tile's Title now, a click handing it to the route to center, a deleted one shown broken. A Message the user sends goes through the route, which posts it after the navigation it follows, from the view it was sent from, and a Turn answers it, in the Tile the Message opens with a link to, else the centered one; while it runs the input waits, the agent's step shows live, and a Stop ends it. Beside the input, the Mode: in ask the assistant's changes come as one Proposal, an Entry listing them, which the user accepts whole or discards where it stands, then says how it was decided; in apply they land as it goes.
