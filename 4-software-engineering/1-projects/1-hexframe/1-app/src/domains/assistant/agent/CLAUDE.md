# agent

A sub-model of [[4-software-engineering/1-projects/1-hexframe/1-app/src/domains/assistant/CLAUDE|Assistant]]: how a Turn's agent, Claude Code, is started and heard. `agent.ts` runs it, called by the API layer as directly as the service, as Mapping's `landing/` is, over the sandbox and the Turns repositories and the service's Entries and Turns (`../assistant.ts`); the other files are pure, the rules it runs. Not part of Assistant's door: the front never reads it. Like `../spending/`, it speaks the words of what it talks to, Claude Code's here (`stream-json`, `tool_use`, `result`), since it is a rule on what Claude Code writes and reads, unchanged.

| File | Holds |
|---|---|
| `agent.ts` | `writeSystem`, the System written into the Account's sandbox, ensured first, the whole of its System folder, read-only, answering the sandbox; `latestToday`, today's latest Entries, as many as a prompt holds (`settings.turn.entries`); `startAgent`, a Turn's agent started (`TurnStart`): the System written, its prompt, settings and launcher written beside the System folder, the launcher started in the location's folder, and stopped at once should a Stop have ended the Turn while it started; `stopAgent`, a Turn's agent interrupted, then killed past a grace; and `followTurn`, one line the agent wrote, read by `readLine`, its events followed in order on the Turn still running: its text recorded as the agent's Message, its step set then dropped, its result or its exit ending the Turn through the service's `endTurn`, a line that is no event `Malformed` |
| `prompt.ts` | `promptOf`, what the agent is told beside Claude Code's own prompt (`--append-system-prompt-file`): its files are a read-only snapshot of the System as the Turn started; how the System is read and written, the lines the API layer words from the MCP's tool table and hands in (`systemRules`), the tools, a Conflict and Help named there and nowhere here, so a tool renamed never leaves the prompt behind (`hexframe-app-assistant/decisions.md#DEC-21`); in ask its writes are drafted into one Proposal the user accepts or discards, which its reads and its files show over the System, in apply they land as they come; where it starts; the Tiles on the user's screen, by Title and Preview (`Glimpse`, the shape Assistant reads Mapping's by); and today's latest Entries, each as a line, a Proposal with its changes and how it stands. The Tiles the Message links (`Linked`), each with its file from the System folder and from where the agent starts (`relativePath`), as the System holds it now, or gone; the rules say `@[<id>]` links a Tile and a Message opening with one starts the agent there. Every text of the System and the timeline is quoted as one JSON string, in fenced blocks the prompt calls data, so none reads as a rule of the Turn. Every ancestor's `CLAUDE.md` loads by itself from its working folder, so the System's own words are not repeated. No secret is ever in it |
| `launch.ts` | `launchOf`, the files a Turn writes beside the System folder, under `turns/<Turn>/`, its prompt, its settings (`turn.json`) and the launcher, and the process it starts (`processOf`, by the Turn's id): `exec node <launcher>`, in the Tile's folder, for `settings.turn.longest`, with the Turn's Key in its environment as `HEXFRAME_TURN_KEY` and `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` at the proxy, the settings' models, and Claude Code's experimental betas and nonessential traffic off. ## Rules

- **The Turn's Key never reaches a file nor a command line.** `launchOf` writes it into the process's environment and nowhere else; the MCP client's config names it there for the agent to expand. `agent.test.ts` holds both.
- **What the user's System says is data, never a rule.** A Title, a Preview, a Message or a Key's name reaches the prompt quoted, one line each, inside the fenced blocks.
- **No Turn leaves anything to the next.** The System folder is rewritten whole, and the sandbox gives each process a HOME of its own, the rest of the work folder cleared, before its agent starts.
- **A Key the agent says is masked before it is kept**, in its Messages and its steps: an agent printing its environment leaves no secret in the timeline.
- **The agent's words are read by a schema, and only what Assistant keeps.** A field Claude Code adds tomorrow is left out, a line it renames is none, and the door answers it 400.
- **The fake agent is the sandbox's, not Assistant's.** On this machine the sandbox runs it in Claude Code's place, behind the same arguments ([[4-software-engineering/1-projects/1-hexframe/1-app/src/repositories/agent/sandbox/CLAUDE|sandbox]]); nothing here knows which runs.
