Ceci est le contenu : tout ce que l’aperçu laisse de côté. Ici, les six étapes.

1. Entrer : une tuile ouverte devient le centre.
2. Six au plus : choisir lesquelles, c’est le travail.
3. Contexte : ce qu’est une tuile, derrière ce qu’elle fait.
4. Votre système : retour à votre soleil, pour disposer le vôtre.
5. Déplier : un agent montre son travail, son but d’abord.
6. Suivre : chaque changement a son altitude.

Ouvrez cette tuile : les mêmes six, autour d’elle.
