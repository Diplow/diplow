# Deckbuilding — heuristiques transversales

Ce dossier contient des **principes de deckbuilding transversaux** — pas spécifiques à une légende. Distinct de `decks/` qui contient des guides de pilotage de listes précises.

Chargé automatiquement par la skill `/games:riftbound:deckbuild`. À enrichir au fur et à mesure : chaque fois qu'un raisonnement deckbuilding se révèle **réutilisable au-delà du deck en cours**, en faire un fichier ici (au lieu de le laisser enterré dans une conversation).

## Index

- [`archetype_identity.md`](archetype_identity.md) — chaque carte doit servir une identité de plan de jeu précise
- [`threat_distribution.md`](threat_distribution.md) — mono-menace vs. menaces réparties : trade-off structurel

## Format attendu

Un fichier = un concept. Court (1-3 écrans). Structure type :
1. **Principe** en une phrase.
2. **Pourquoi** ça compte (la faiblesse / le coût qu'on évite).
3. **Comment appliquer** : signaux observables, heuristiques pratiques.
4. **Exemple concret** tiré d'un deck du projet quand disponible.
